# Sandcastles.ai Research Report

**Date:** January 1, 2026
**Focus:** Product analysis, data presentation approach, comparative positioning vs Research Agent

---

## Executive Summary

**Sandcastles.ai** is a niche content research + scriptwriting platform focused exclusively on **short-form viral video creation** (TikTok, Instagram Reels, YouTube Shorts). It's NOT a general documentary research tool like Research Agent.

**Core positioning**: Creator toolkit for finding viral videos → extracting proven formulas → writing scripts that replicate viral patterns.

**Key insight**: Highly specialized vertical (video scripts only) vs Research Agent's horizontal approach (multi-format research packets).

---

## 1. What is Sandcastles.ai?

### Product Definition
An AI-powered platform that automates viral video research and scriptwriting for content creators.

**Tagline**: "Create viral short-form videos in seconds"

### Primary Use Case
Creators (YouTubers, TikTokers, Instagrammers) who want to:
- Study what's working in their niche
- Understand viral video formulas
- Write scripts faster using proven patterns
- Build reusable template libraries

### Creator Target
- Creators at all scales (from new to scaled)
- 1M+ follower creators (built by Kallaway, a creator with 1B+ views)
- Focus: Speed + virality over depth/nuance

---

## 2. How Sandcastles.ai Presents Research Data

### Research Workflow
```
1. Add channels to watchlist (any platform: Instagram, TikTok, YouTube)
2. Platform identifies top viral outliers in that cohort
3. View instant transcripts + detailed analysis
4. Extract hooks, storytelling structure, visual styles
5. Save winning elements to personal "Vault"
6. Generate variations or write new scripts
```

### Data Presentation Approach

#### Search & Discovery
- **Watchlist building**: Track unlimited favorite channels
- **Viral ranking**: "One-click shortcut to figuring out exactly what's working in your niche"
- **Database**: Millions of validated outliers across platforms
- **Filtering/Sorting**: Search, filter, and sort to find patterns

#### Content Analysis Output
For each analyzed video, users receive:

| Element | Format | Purpose |
|---------|--------|---------|
| **Transcripts** | Plain text | Understand dialog + pacing |
| **Hook breakdown** | Text analysis | Why it captured attention |
| **Story structure** | Narrative breakdown | Beginning/middle/end patterns |
| **Visual format** | Categorized tags | Camera angles, cuts, transitions |
| **Writing style** | Stylistic notes | Tone, pace, language patterns |

#### Actionable Insights Layer
- **Why it outperformed**: Analysis of viral mechanics
- **How to replicate**: Specific learnings for own content
- **Exportable patterns**: Can copy analysis to ChatGPT/Claude for further iteration

### Output Formats Available

**Native outputs:**
1. **Hook variations** - Dozens of hook templates in seconds
2. **Scripts** - Production-ready video scripts (text format)
3. **Vault collections** - Saved hooks + writing styles as reusable templates
4. **Project/watchlist exports** - On higher-tier plans

**Integration outputs:**
- Copy-paste analysis into external AI tools (ChatGPT, Claude)
- No direct video file exports
- No document generation (no PDFs, no NotebookLM packets)

## 3. Data Organization & Presentation Features

### The "Vault" Feature (Dec 2025 Update)
**Purpose**: Personal archive of winning viral formulas

**Functionality**:
- Press "Save to Vault" on any video
- Extract 2 reusable elements:
  1. **Viral hooks** - Opening lines that capture attention
  2. **Writing styles** - Narrative structures + stylistic patterns
- Organized within scriptwriter workflow: Prompt → Research → Hook → Style → Script

**Benefit**: "Fastest path to generating new viral winners"

### Organization System
- **Watchlists**: Unlimited collections of favorite channels
- **Projects**: Group research by topic/theme
- **Vault**: Personal template library of proven formulas
- **Collections**: Custom saved patterns

### UI/UX Approach
- Creator-native workflow (not researcher-native)
- Integrated research → script pipeline
- Visual reference (video-centric, not text-centric)
- Real-time transcripts on demand

## 4. Comparison to Research Agent

### Fundamental Positioning

| Aspect | Sandcastles.ai | Research Agent |
|--------|---|---|
| **Primary audience** | Short-form video creators | Documentary researchers/producers |
| **Input** | Existing viral videos | Raw topic (text research brief) |
| **Pipeline** | Analyze → Extract → Remix | Discover → Analyze → Synthesize → Output |
| **Output focus** | Script text | Multi-format packets |
| **Time horizon** | Real-time (what's viral NOW) | Timeless (investigation/profiles) |
| **Platform scope** | Video platforms only | Web + Reddit + YouTube + News |

### Output Comparison

**Sandcastles.ai outputs:**
- Video transcripts (extracted)
- Hook variations (generated)
- Video scripts (generated text)
- Personal template vaults
- Analytical breakdowns

**Research Agent outputs:**
- NotebookLM packets (AI podcast-optimized)
- Documentary blueprints (video production-optimized)
- JSON exports (structured data)
- Citation packages
- Social media clips (extracted)
- Social kits (multi-format)
- Timeline visualizations
- Entity networks (graphs)

### Data Presentation Philosophy

**Sandcastles**: Minimize analysis depth, maximize template reusability
- Focus: Hook/formula extraction
- Depth: Shallow (what works, not why)
- Format: Focused on generation (hooks → scripts)

**Research Agent**: Maximize narrative complexity, support multiple consumption formats
- Focus: Comprehensive context building
- Depth: Deep (claims, validation, timeline, actors, relationships)
- Formats: Podcasts, documentaries, summaries, JSON, clips

### Key Differentiators

#### 1. Scope
- **Sandcastles**: Single-purpose (viral video scripts)
- **RA**: Multi-purpose (podcast, documentary, research packets)

#### 2. Research Sources
- **Sandcastles**: Video platforms only (existing content)
- **RA**: Multi-source (web, Reddit, YouTube, news)

#### 3. Analysis Depth
- **Sandcastles**: Surface-level pattern extraction ("what works")
- **RA**: Deep research ("why it matters, what happened, who was involved")

#### 4. Output Format Specialization
- **Sandcastles**: Scripts only (writer focused)
- **RA**: Format-specific packets (podcast vs documentary)

#### 5. Reusability Model
- **Sandcastles**: Formula templates (save hooks/styles for reuse)
- **RA**: Content artifacts (save research packets for reuse across channels)

## 5. Strategic Insights for Research Agent

### What Sandcastles Does Well
1. **Hyper-focused vertical**: Single use case = cleaner UX/product market fit
2. **Creator-native workflow**: Pattern extraction → remix → generation (feels natural)
3. **Real-time relevance**: Captures "what's viral NOW" (timeliness advantage)
4. **Low cognitive load**: Users don't wade through deep analysis layers

### Where Research Agent Differs
1. **Horizontal scope**: Works across research modes (breaking_news, investigation, profile, controversy)
2. **Depth + breadth**: Claims, timelines, entities, relationships (not just formulas)
3. **Format specialization**: NotebookLM (audio) and Documentary (video production) outputs
4. **Credibility focus**: Citations, validation, quality gates (not viral metrics)

### No Direct Competition
- **Sandcastles**: Optimized for "what makes videos go viral"
- **Research Agent**: Optimized for "what makes research credible"
- Different audiences, different problems, different outputs

## Conclusion

Sandcastles.ai is a **specialized vertical tool** for a different market (video creators) with a different output (scripts). Not a competitor to Research Agent, but demonstrates value in **deeply optimized workflows for specific use cases**.

Research Agent's advantage: Multi-format outputs + research credibility focus. Sandcastles' advantage: Creator-native simplicity + real-time viral pattern extraction.

No existential threat, but useful reference for understanding **how specialized research tools can succeed with focused positioning**.
