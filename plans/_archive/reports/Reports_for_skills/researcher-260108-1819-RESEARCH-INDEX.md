## Key Insights (Not in Other Documents)

### Insight 1: Skills Work Across All Claude Products
Not just Claude Code. Skills you create work in:
- Claude Code (primary)
- Claude Web interface
- Claude API (agents feature)
- Claude for Teams

**Implication:** Skills created for Research Agent are investments that pay off everywhere.

### Insight 2: Hooks Are the Missing Piece for Production
Most teams use CLAUDE.md + Skills. Hooks are what separates "helpful AI helper" from "production CI/CD tool."

**Implication:** Hooks are the highest-leverage addition for research quality.

### Insight 3: Context Compaction Is Anthropic's Secret Sauce
Claude Code can run indefinitely because it automatically compacts context, creating summary notes, and resuming with fresh context.

**Implication:** Multi-day research jobs don't degrade. But we should monitor quality metrics.

### Insight 4: "Extended Thinking" Is Not for Everything
- Use "think" for algorithm design
- Use "think hard" for validation logic
- Use "think harder" for major architectural decisions

**Implication:** Add guidance to CLAUDE.md about when to invoke thinking budget.

### Insight 5: Structured Outputs Eliminates Retry Logic
Claude's native structured outputs guarantee schema compliance without retry loops.

**Implication:** Research Agent extraction pipeline could drop ~20 lines of validation code.

## Frequently Asked Questions

**Q: Is ClaudeKit an external tool I need to install?**
A: No, it's a set of patterns and best practices. You create SKILL.md files and hooks yourself. Optional: Install `claudekit-cli` for pre-built skills.

**Q: Will implementing ClaudeKit break my existing CLAUDE.md?**
A: No. It enhances it. You're just adding sections and organizing better.

**Q: How long until we see benefits?**
A: Immediately. Enhancements to CLAUDE.md take effect in next session. Skills become active once created.

**Q: What if Claude doesn't activate the right skill?**
A: Skills descriptions are critical. They must be specific enough for Claude to decide when to use them. See Comprehensive Report section 2.2 for best practices.

**Q: Do hooks slow down development?**
A: No, they speed it up. They eliminate manual verification steps (running tests, checking for secrets).

**Q: What's the learning curve?**
A: Low. You're mostly writing markdown files (SKILL.md) and bash scripts (hooks). No new languages.

**Q: Can we customize skills for Research Agent?**
A: Yes, completely. The roadmap provides templates. You should modify them to match your team's standards.
