KEY FINDINGS SUMMARY
================================================================================

VIDEO INPUT:
✅ YouTube URLs supported directly (no upload)
✅ File upload via API for non-YouTube videos
✅ Inline data for <20MB videos
✅ Up to 10 videos per batch request (Gemini 2.5+)

TIMESTAMPS:
✅ Automatic MM:SS format (second-level precision)
✅ Query-specific timestamps ("Find moments about X")
✅ Temporal reasoning (ordering, duration, correlation)
✅ Scene detection for clip boundaries

EXTRACTION ACCURACY:
✅ Quote extraction with speaker attribution
✅ Speaker diarization (built-in)
✅ Cross-video contradiction detection
✅ Moment retrieval using audio-visual cues
⚠️ Works best for 2-3 speakers (degrades with 4+)

PRICING:
✅ Flash: $0.14/hour (84.7% accuracy)
✅ Pro: $1.16/hour (85.2% accuracy)
✅ Hybrid: $0.35/hour (recommended)
✅ 50-70% cheaper than current Supadata+LLM approach

LIMITATIONS:
⚠️ 1 FPS sampling loses fast-motion frames (LOW impact for interviews)
⚠️ Complex reasoning over 3+ hours shows degradation (MEDIUM impact)
⚠️ Speaker ID requires context (LOW impact for documentaries)
⚠️ Non-speech audio sometimes misidentified (LOW impact)

MULTIMODAL ADVANTAGE:
✅ Captures visual context (expressions, body language)
✅ Detects contradiction from both audio and visual cues
✅ Higher accuracy on speaker attribution vs transcripts
✅ Semantic moment retrieval vs keyword-only search
