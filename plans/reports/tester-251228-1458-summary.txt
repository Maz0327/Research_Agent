HIGH PRIORITY ISSUES (P1-P3):
1. Missing page_size validation in admin queries (GET /admin/jobs, /admin/errors)
   - Users can request page_size=999999 causing memory exhaustion DoS
   - Affects 2 endpoints
   - FIX: Add le=MAX_PAGE_SIZE to Query parameters

2. No date format validation on admin filters
   - Date parameters should validate ISO 8601 before passing to Supabase
   - Affects 2 endpoints
   - FIX: Add validation function to check date format

3. Admin routes completely missing rate limits
   - No rate limiting at all on admin endpoints
   - Vulnerable to admin DoS attacks
   - Affects 8 admin endpoints
   - FIX: Add @limiter.limit() decorators to all admin routes

4. Slack endpoint missing rate limiting
   - Can be spammed with slash commands
   - FIX: Add rate limit decorator (10/minute recommended)

MEDIUM PRIORITY ISSUES (P4-P7):
5. Video URL validation missing in /transcripts POST
   - No format checking, accepts non-YouTube URLs
   - No limit on video count (could accept 1000+ videos)
   - FIX: Add YouTube URL regex validation + count limit

6. Ban check not cached
   - Every authenticated request hits database
   - Performance issue under load
   - FIX: Cache with 5-10 minute TTL

7. Manual form parsing in Slack route
   - Should use FastAPI Form() parameters instead
   - Error-prone, doesn't handle duplicates
   - FIX: Refactor to use Form() parameters

8. No test coverage for admin/settings/transcripts/slack routes
   - Missing: test_admin_routes.py
   - Missing: test_settings_routes.py
