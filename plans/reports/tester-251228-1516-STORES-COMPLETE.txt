   File: admin.ts (189-267)
   Issue: Production errors only logged in development, silent failure
   Impact: Cannot debug issues in production
   Fix: Add error field to AdminState, log all errors
   Effort: 1 hour

   File: jobs.ts (58-92)
   Issue: User logged out but no notification shown
   Impact: User confusion about why jobs disappeared

   Effort: 1 hour

   File: settings.ts (85-86)
   Issue: Module-level global timeout variable fragile
   Impact: Edge cases with multiple instances
   Fix: Move timeout ID to Zustand state

HIGH PRIORITY ISSUES - BEFORE RELEASE
================================================================================

5. NO ERROR STATE IN STORES
   Files: admin.ts, jobs.ts
   Issue: AdminState and JobsState lack error field
   Impact: Cannot display errors to users
   Fix: Add error: string | null to both stores
   Effort: 2 hours

6. JSON PARSE ERRORS UNHANDLED
   Files: admin.ts (162), jobs.ts (85), settings.ts (142, 175, 217, 255)
   Issue: Malformed JSON crashes without fallback
   Impact: Unexpected crashes
   Fix: Wrap all response.json() in try/catch
   Effort: 2 hours

7. REFRESHJOB UNDEFINED OVERWRITES
   File: jobs.ts (144-177)
   Issue: Incomplete API response overwrites good data with undefined
   Impact: State corruption, lost job data
   Fix: Only update fields that are defined
   Effort: 1 hour

8. FOLDER MUTATIONS
   File: settings.ts (306-327)
   Issue: Direct object mutation instead of immutable updates
   Impact: React may miss change detection
   Fix: Create new objects with spread operator
   Effort: 1 hour

9. SUPABASE ENV VAR WARNING
   File: supabase.ts (6-16)
   Issue: Warning only in production, silent in dev
   Impact: Dev confusion about config
   Fix: Always warn or throw in dev
   Effort: 0.5 hour

10. PAGINATION RESET
    File: admin.ts (119-126, 215-240)
    Issue: Page number stale after filter change
    Impact: Shows wrong data after filtering
    Fix: Reset to page 1 when filters applied
    Effort: 1 hour
