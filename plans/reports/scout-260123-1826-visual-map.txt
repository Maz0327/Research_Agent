CRITICAL DECISION POINTS
────────────────────────────────────────────────────────────────────────────────

✓ Source Isolation (RULE 1)
  Each source → separate LLM call (no cross-contamination)

✓ Confidence Ceilings (RULE 2)
  Mode-specific limits enforced in validation stage
  HIGH: 0.8-1.0
  MEDIUM: 0.5-0.8
  LOW: 0.3-0.5

✓ Prompt Components (RULE 3)
  ALL LLM prompts require 5 components:
  1. Source Identity Lock
  2. Confidence Ceiling Declaration
  3. Empty Output Permission
  4. Layered Extraction (L1 → L2 → L3)
  5. Output Schema

✓ Pipeline Order (RULE 4)
  INGESTION → EXTRACTION → VALIDATION → SYNTHESIS → ASSEMBLY → UPLOAD → COMPLETION
  Never skip. Never reorder.
